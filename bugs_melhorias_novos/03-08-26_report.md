# MELHORIAS

## Criar botão de reorganizar Canvas
- O botão deve ficar junto ao menu lateral, em uma seção de botões de ação que serão criadas
- O botão "Reorganizar" deverá agrupar automaticamente, todos os widgets do canvas para que ocupem 100% das colunas disponíveis
- A ação deve afetar somente widgets que não estiverem bloqueados

## Afastar o botão de "Cadeado" do botão de Fechar "X"
- O botão está muito próximo, e o usuário pode clicar sem intenção em um botão que não gostaria

## Adicionar ícones para cada widget existente e a ser criado
- Quando entra no modo compacto, alguns nomes possuem a mesma inicial e fica difícil diferencia-los
- Os ícones podem ser emojis que se relacionem com a função proposta pelo widget

## Editar tarefas criadas
- Hoje, depois que o usuário cria uma nova tarefa, ele não consegue editá-la. Ele precisa apagar e criar uma nova
- Dar a opção de edição da tarefa após 2 cliques. 1 clique, marca como concluida, 2 cliques rapidos permite editá-la

## Widgets não estão ocupando 100% da área visível
- Hoje, o canvas só é preenchido 100% na horizonal se o usuario adiciona 3 widgets no tamanho padrão. Se o usuário faz a alteração da largura de algum dos widgets adicionados, o espaço que sobra à direita não é preenchido automaticamente. Só é preenchido se o usuário redimensionar um 4º widget e arrastá-lo manualmente para o espaço

## Gerenciador de Snippets agrupar por categoria
- Quando o usuário insere 5 snipptes, de no máximo 2 linhas, o visual comporta exibir todos eles. Porém, se o usuário adiciona mais snippets ou excede mais linhas cada um, os snippets salvos começam a diminuir de tamanho e colapsar, ficando dificil a visualização do conteúdo.
- O gerenciador deve possuir uma barra de rolagem vertical e exibir até 5 snippets. Além disso, o usuário terá que rolar a barra para visualizar os demais
- Adicionar também, uma opção de agrupar snippets por categoria já criada. Assim, o usuário pode selecionar a categoria e visualizar apenas os snippets daquela categoria
- E uma terceira função pode ser criada para "favoritar" ❤️ os snippets mais usados. O botão de seleção pode ser semelhante ao usado no timer multitarefas: "Todos / Categorias / Favoritos"

## Criar um script que inicialize o dashboard com 1 clique
- O script deverá aproximar o funcionamento do dashboard de um aplicativo real, onde o usuário clica e executa um único comando e automaticamente: O dashboard é construido, o ambiente virtual é inicializado, o agente é iniciado e o dashboard é exibido em uma nova janela indepentente
- A execução do dashboard também deverá acontecer sem a necessidade do terminal permanecer aberto. Se o usuário fecha o terminal sem querer, acaba perdendo a conexão com o dashboard.

## O botão de "+ Adicionar" está cobrindo o nome dos widgets
- Colocar o botão de adicionar logo abaixo da descrição do aplicativo

## Bloco de Anotações multitarefas
- Hoje, o bloco de anotações rápidas permite a edição de texto simples.
- Adicionar uma função que permita o usuário escolher entre: Texto Simples/Rich Text/Markdown.
- A opção Rich Text deve oferecer recursos básicos: Negrito, Itálico, Sublinhado, Lista, Hiperlink
- A opção Markdown deve oferecer também a opção de renderizar o conteúdo

## Dar foco aos widgets recém adicionado e todo o canvas
- Hoje, quando o usuário adiciona novos widgets, eles são acumulados na parte inferior da tela e o usuário precisa navegar manualmente para o fim da página para visualizar o novo recurso
- Faça com que a adição de novos widgets movimente a tela automaticamente, para que o foco esteja no aplicativo recém adicionado.
 -Adicione também, um botão de ação que permita o usuário visualizar o canvas inteiro, com todos os aplicativos em uso.
 
 ## Botão "Nuke" para encerrar todos os aplicativos
 - Adicionar um botão "Nuke" 💣 para encerrar todos os aplicativos em execução. 
 - A ação deverá apagar também todos os dados/notas armazenados.
 - A ação deverá afetar tanto os aplicativos pinned quanto os upinned.
 
 ## Centralizar as configurações de aparencia do dashboard em um unico arquivo
 - Criar um arquivo (ou evidenciá-lo, caso exista), onde o desenvolvedor possa modificar a aparencia global do dashboard: tamanho dos grids, espaçamento, bordas, cores do tema, etc.
 - Esse arquivo será útil para um estado avançado, quando eu quiser personalizar e criar temas especiais para o dashboard (natal, páscoa, trabalho, estudo, etc).

# BUGS

## Timer para a contagem quando muda o modo
- A proposta é que o usuário selecione qual dos 3 modos deseja que o timer funcione. Quando o usuário clica em iniciar, as outras funções devem ficar ocultas ou desativadas
- O usuário só poderá mudar de função caso CANCELE ou AGUARDE O TEMPO corrido (exceto o cronometro)

## Widgets são movimentados quando o usuario arrasta um aplicativo sobre ele
- Quando o usuário clica a arrasta um aplicativo sobre a tela, os outros aplicativos que já estão posicionados são movimentados para o final da tela (nova linha), o que prejudica toda a organização do usuário.

# Novos Widgets (aplicativos)

## Mini-Kanban
- Um aplicativo que ofereça um kanban simples: "à fazer / em andamento / concluído"
- Os cards deverão receber texto simples de até 50 caracteres. Pode aceitar emojis
- Os cards poderão ser movimentados por clicar/arrastar ou através de botões no próprio card: 🌑🌓🌕 (1 clique, 0: a fazer | 2 cliques, 50: em andamento | 3 cliques, 100: concluido)
